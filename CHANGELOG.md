# 1.1.0 — Public portfolio release

This release establishes a coherent public identity and a fresh public integrity baseline. It preserves the extension's production architecture and behavioral coverage while removing private-development provenance and internal release-state material.

## Public-release changes

- Unified manifest, runtime Build ID, documentation, package name, release tag, and release tooling on version 1.1.0 / `v1.1.0-public-20260908`.
- Described protocol fixtures accurately as privacy-sanitized, de-identified, capture-derived behavioral fixtures and removed source linkage/private metadata.
- Separated the immutable release/freeze integrity gate from normal fast/full behavioral development suites.
- Replaced a lexical storage-call count with structural assertions around the actual persistence owners and forbidden shadow-stat state.
- Removed obsolete raw-capture validation tooling and internal scratch/handoff documentation from the public copy.

## Capabilities

- Live Seat HUD and leaderboard with configurable Session/Career statistics.
- Persistent local Career history, health reporting, backup, preview, and replace-only restore.
- Player dashboard, position/relational filters, stable-ID notes, and interpretable profiles.
- Hands, VPIP, PFR, AF, 3Bet, F3B, flop CBet/FCB, WTSD, and W$SD.
- Persistent Pot Odds companion plus configurable overlay placement and lifecycle-safe rendering.
