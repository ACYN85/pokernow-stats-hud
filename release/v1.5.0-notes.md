# PokerNow Stats HUD v1.5.0

V1.5 improves large-history performance and reliability, with a certified runtime and Export → Replace → Merge portability target of **150,000 physical records**.

- Faster large-history reads, bounded derived-state rebuilding and cleanup, and persistence/atomicity hardening.
- History navigation with paged Session lists and detail controls.
- Recent windows for the last 3/5/10 Sessions or 100/250/500 hands, with Career comparisons.
- Session Trends and persistent Dashboard open/player/source navigation across reload.
- Backup v2 streaming export, Replace, and Merge from Settings → Data. Backup v1 compatibility is retained for small histories within its existing limits.

**Replace** replaces Career with the backup and resets the current Session selected by the transfer page. **Merge** combines compatible Career histories, deduplicates identical records, rejects conflicts rather than overwriting them, and preserves the current Session.

Always export Backup v2 to a **fresh filename**: interrupted overwrite of an existing file can destroy its old content. Incomplete backups are invalid; interrupted transfers are not durably resumable. Raw reads before derived READY may take minutes, and very large rebuilds may take substantial time. 250k portability is not certified. IndexedDB physical disk compaction is not immediate or guaranteed. See [Known Limitations](../KNOWN_LIMITATIONS.md) and [Career Data](../CAREER_DATA.md).

This extension analyzes information visible during PokerNow games and stores derived statistics locally. It does not access hidden cards, infer hidden information, automate gameplay, make betting decisions, recommend actions, provide solver output, or calculate live equity, EV, or outs strategy. Pot Odds displays arithmetic from supported visible pot and call-cost information.

The final asset is a byte-identical copy of the manually accepted RC2 archive. The runtime Build ID remains `v1.5.0-rc2-20261006-2218`.
